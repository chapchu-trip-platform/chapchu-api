== 개요

PetTrip 반려동물 동반 여행 플랫폼 REST API 명세입니다.

== 공통

=== 요청 헤더

[source,http]
----
Authorization: Bearer {access_token}
Content-Type: application/json
----

=== 응답 코드

|===
| 상태 코드 | 설명

| `200 OK` | 성공
| `201 Created` | 생성 성공
| `400 Bad Request` | 요청 파라미터 오류
| `401 Unauthorized` | 인증 필요
| `403 Forbidden` | 권한 없음
| `404 Not Found` | 리소스 없음
| `500 Internal Server Error` | 서버 오류
|===

=== 닉네임 중복 확인

`GET /users/nickname/check?nickname={nickname}`

닉네임은 유저 간 중복될 수 없습니다. 이 API는 조회 시점 기준의 사전 안내이며 **예약 효과가 없습니다**.
확인과 등록 사이에 다른 유저가 선점할 수 있으므로, 최종 판정은 닉네임 등록/수정 요청의 `409 Conflict` 응답으로 처리하세요.
